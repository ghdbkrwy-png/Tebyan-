# تِبيان — تطبيق قراءة وتلخيص وسرد المستندات (على غرار NotebookLM)

تطبيق جاهز للنشر على Netlify. الواجهة الأمامية (HTML/CSS/JS عادي، بدون أي بناء/build)
تتواصل مع سلسلة Netlify Functions التي تنادي Gemini API لتنفيذ كل ميزة.

## المزايا

| الأيقونة | الميزة | ماذا تفعل |
|---|---|---|
| نظرة عامة | تحليل أولي | عنوان المستند، لغته، نوعه، ومحاوره الرئيسية |
| ملخّص | تلخيص | نقاط رئيسية بثلاث مستويات تفصيل |
| محادثة | Chat مرتكز على المصدر | إجابات مبنية حصريًا على محتوى الملف |
| دليل الدراسة | Study guide | مصطلحات + أسئلة شائعة + اختبار قصير |
| شرائح | شرائح مشروحة | تحويل الملخّص لشرائح، مع زر استماع لكل شريحة |
| نظرة صوتية | Audio Overview | حوار بين "مذيع" و"مذيعة" حول المستند، مُولَّد نصًا ثم صوتًا بصوتين مختلفين (أشبه ببودكاست NotebookLM) |

## من أين تجيب مفتاح Gemini المجاني بالضبط

1. افتح **https://aistudio.google.com/apikey**
2. سجّل دخول بحساب Google عادي (Gmail).
3. اضغط **Create API key** → اختر مشروع موجود أو "Create key in new project".
4. انسخ المفتاح مباشرة — ما بتحتاج تضيف بطاقة ائتمان، لأن نماذج عائلة **Flash** (النصّية والصوتية) مجانية ضمن حدود استخدام يومية (rate limits)، والمفتاح نفسه يشتغل على كل الدوال بهذا المشروع (قراءة PDF، تلخيص، محادثة، صوت).

⚠️ ملاحظتين مهمتين:
- الاستخدام على الفري تير بيتيح لـ Google استخدام طلباتك لتحسين منتجاتهم (مذكور بصفحة الأسعار). إذا هاد مهم لخصوصيتك، فيه فري تير أوسع لو ربطت المشروع ببطاقة (Billing) بدون ما تتوقف الأسعار المجانية عن الانطباق ضمن الحدود.
- نماذج TTS (`gemini-3.1-flash-tts-preview` وسابقتها `gemini-2.5-flash-preview-tts`) لسا بحالة **preview** من غوغل، يعني ممكن تتغير حدودها أو تسعيرتها بأي وقت — الكود مكتوب بحيث يجرّب النموذج الأحدث وإذا فشل (404) يرجع تلقائيًا للنموذج الأقدم.

## النماذج المستخدمة (آخر تحديث: أغسطس 2026)

معرّفة بمتغيّر بأعلى ملف `netlify/functions/_lib.js` — غيّرها من هناك فقط إذا صدر نموذج أحدث:

```js
MODEL_TEXT = 'gemini-3.7-flash'              // للقراءة والتحليل والتلخيص والمحادثة
MODEL_TEXT_FALLBACK = 'gemini-2.5-flash'
MODEL_TTS  = 'gemini-3.1-flash-tts-preview'   // للصوت (شرائح + النظرة الصوتية)
MODEL_TTS_FALLBACK  = 'gemini-2.5-flash-preview-tts'
```

## خطوات النشر على Netlify

1. فك ضغط هذا المجلد وارفعه إلى مستودع Git (GitHub/GitLab)، أو اسحبه مباشرة بخانة
   Deploy manually في لوحة Netlify.
2. من إعدادات الموقع على Netlify: **Site configuration → Environment variables**
   → أضف متغيّرًا باسم `GEMINI_API_KEY` وقيمته المفتاح الذي نسخته من الخطوة السابقة.
3. أعد نشر الموقع (Trigger deploy) بعد إضافة المتغيّر حتى تُطبَّق الدوال عليه.
4. الدوال بتشتغل تلقائيًا تحت `/.netlify/functions/...`، والواجهة بتنادي المسار
   المختصر `/api/...` المُعاد توجيهه بملف `netlify.toml`.

## البنية

```
tibyan-app/
├── index.html              الواجهة (شكل NotebookLM: شريط أيقونات + لوحات)
├── style.css
├── app.js                  منطق الواجهة ونداء الدوال
├── netlify.toml
├── package.json
└── netlify/functions/
    ├── _lib.js              مشترك: نداء Gemini، CORS، تحويل PCM→WAV
    ├── analyze.js           نظرة عامة
    ├── summarize.js         ملخّص
    ├── chat.js               محادثة
    ├── study-guide.js       دليل الدراسة
    ├── slides.js             بناء الشرائح من الملخّص
    ├── tts.js                 صوت شريحة واحدة (متحدث واحد)
    └── audio-overview.js    نظرة صوتية (متحدثان)
```

## ملاحظة على الخصوصية

الملف يبقى في متصفح المستخدم فقط، ولا يُرسل base64 الخاص به إلا عند الضغط على زر
فعلي (تحليل / تلخيص / محادثة / دليل دراسة / نظرة صوتية) إلى دالة Netlify الخاصة بك،
والتي بدورها ترسله لـ Gemini API بمفتاحك. لا يوجد أي تخزين دائم للملف على أي خادم.
